How this test works +
A fixed, legal shuffle
The default test uses a seeded 20-move sequence to create the starting state. Each selected model gets a separate copy. The seed makes the test repeatable. This is a random-move shuffle, not a uniform sample of all cube states.
Three separate protocols
Jev selects one of 18 classes through the decisions API. Astra, Luna, and Sol use a JSON schema with the same 18 choices. Each request contains the full state, orientation rules, and applied move history. The improved protocol also supplies each possible next state and retains a written plan for Astra, Luna, and Sol. The original and plan-memory protocols use no solver. The optional solver-assisted control supplies a verified solution plan. Its results do not measure independent solving.
Honest limits
In the default comparison, each model gets up to 500 requests, 8 hours 20 minutes, and $15. The time allowance scales with the request limit, with a minimum of 30 minutes. A request can take up to 120 seconds. Three consecutive errors stop that model. Astra, Luna, and Sol use medium reasoning with up to 16,384 output tokens with plan memory (4,096 in the original protocol). Jev has no equivalent reasoning setting.
What the numbers mean
One face move is one turn, including a half turn. Time includes requests and local processing; replay animation is excluded. Sticker matches are a visual measure, not a measure of distance to a solution. All 54 stickers must match their fixed face centers to pass.
